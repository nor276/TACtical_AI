# TACtical_AI
TAC AI — Cleanup Fork

This is a personal cleanup fork of [TAC AI] by Legionite. It is not a separate mod, is not maintained for public distribution, and is not intended to compete with or replace the original.

This is a heavy revision pass of the code for the sole purpose of increasing maintainability, as well as make changes to the mod more predictable. The shape of the AI is nearly identical to upstream — the changes are broad scattered tweaks, dead code removal, reconnection of orphaned code, and an attempt to restore some functionality that was previously removed. All credit for the mod itself belongs to Legionite and the original contributors.

To Legionite: take anything from here you find useful. No attribution needed, no expectations in any way. If none of it is useful, that's fine too — this exists primarily for my own use.
